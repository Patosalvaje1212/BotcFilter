
El programa funciona tanto ejecutado desde terminal como al lanzar desde normal ( la versión de Linux solo admite terminal ). Para ver las opciones de lanzamiento ejecutar el programa con un -h

Se necesita un archivo "filter.png" que tenga el overlay/filtro que aplicar a las imagenes.
Cada imagen se procesa en rojo y en azul.
El filtro funciona mejor si las imagenes están en blanco y negro, pero funciona igual con imágenes a color, aproximando la luminosidad y por tanto tratándolas como si fueran blanco y negro.
